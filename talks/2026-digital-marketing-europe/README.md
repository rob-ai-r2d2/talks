# Give your AI agent a job, not a prompt

**Conference:** Digital Marketing Europe 2026  
**Speaker:** Robert  
**Length:** about 30–32 minutes, followed by questions

Most of us still use AI one request at a time: notice a task, gather the material, write a prompt, check the answer, and copy it somewhere useful. This talk shows what changes when you give an agent a *job* instead: a saved, recurring responsibility with defined sources, a baseline, rules for what matters, a place to deliver results, and clear limits.

The running example is a competitor-monitoring job for a fictional coffee brand. Three fictional shops (Star Ducks, Caffiend and Hurricup) change on the same day. The agent has to tell the marketing team which change matters (a new subscription offer), which matters less (a one-euro price move), and which to ignore (a complete redesign with an unchanged offer). The agent is built with Hermes Agent, though the idea isn't tied to one framework.

## Notes on the file

The original export was about 161 MB, mostly 3840×2160 PNG backgrounds embedded as base64, which is over GitHub's 100 MB per-file limit. For this repo the large PNGs were converted to WebP (quality 85, same resolution, alpha preserved), bringing the file to about 30 MB. The rendered slides match the original apart from the animated particles, and the static backgrounds differ by at most a few levels out of 255.
